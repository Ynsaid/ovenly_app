🍕 Ovenly – Pizza Ordering & Delivery App

📌 Overview
Ovenly is a mobile app built with Kotlin and Jetpack Compose that allows users to browse a wide variety of pizzas, view detailed ingredients for each type, and order fresh pizzas for home delivery.

✨ Features

🍽 Pizza Menu – Browse different types of pizzas.
🔍 Ingredient Transparency – View exact ingredients for each pizza.
🛒 Order System – Add pizzas to cart and place orders easily.
🚚 Fast Delivery – Get your order delivered fresh and hot.
📱 Modern UI – Built with Jetpack Compose for a smooth experience.


🛠 Tech Stack

Language: Kotlin
UI Framework: Jetpack Compose
Navigation: Jetpack Navigation Component
Architecture: MVVM
